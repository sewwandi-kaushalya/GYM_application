# 💪 PULSEFIT – Gym & Fitness Website

**Train Hard. Stay Strong. Be Unstoppable.**

PULSEFIT is a modern and responsive gym and fitness website designed to showcase fitness programs, professional trainers, membership plans, and contact information in one place.

The website features a bold design, a dark theme, and vibrant lime-green accents to create an energetic fitness experience.

🌐 **Live Demo:** [Visit PULSEFIT](https://plusefitgy.netlify.app)

---

## ✨ Features

- 🏠 **Home Section** – Attractive hero section with fitness imagery and call-to-action buttons.
- 🏋️ **Fitness Programs** – Showcase different workout programs.
- 👥 **Our Trainers** – Display trainer profiles and experience.
- 💳 **Membership Plans** – Present membership packages and pricing.
- 📩 **Contact Section** – Contact information and message form UI.
- 📱 **Responsive Design** – Optimized for mobile, tablet, and desktop screens.
- 🎨 **Modern UI** – Dark theme with lime-green accent colors.
- 🔗 **Navigation** – Smooth navigation between website sections.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd gym-frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

### 5. Build for Production

```bash
npm run build
```

The production-ready files will be generated inside the `dist` folder.
